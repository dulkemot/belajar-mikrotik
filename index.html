1. Apa itu MikroTik?

Kenalan dulu sebelum pegang router.

MikroTik adalah perusahaan asal Latvia yang membuat RouterOS — sistem operasi khusus router. Sedangkan perangkat fisiknya disebut RouterBOARD (contoh: hAP, RB750, CCR). RouterOS juga bisa dipasang di PC biasa (x86) atau dijalankan sebagai mesin virtual bernama CHR (Cloud Hosted Router, gratis untuk lab dengan limit kecepatan).

💡 Analogi: kalau HP punya Android, router MikroTik punya RouterOS. Bedanya, RouterOS memberi kamu kendali penuh sampai level paket data — makanya dipakai ISP, kampus, hotel, dan warnet.

Lisensi RouterOS

LevelCocok untuk
4 (bawaan hAP/RB kecil)Rumah, lab, AP
5–6ISP kecil, hotspot besar, routing penuh
CHR trial / P1Lab virtual & cloud

2. Cara Akses Router

Empat pintu masuk ke router yang sama.

  • WinBox — aplikasi Windows (jalan juga di Linux via Wine). Paling enak untuk pemula: klik-klik + ada Neighbors untuk menemukan router yang belum punya IP. Login awal: user admin, password kosong.
  • WebFig — buka IP router di browser (tampilan mirip WinBox).
  • SSH / Terminal — untuk perintah teks (CLI). Semua contoh di materi ini memakai CLI karena mudah disalin dan dibuat script.
  • API / Aplikasi — untuk monitoring dan aplikasi buatan sendiri.
💡 Analogi: WinBox itu seperti stir mobil matic, CLI itu seperti mekanik buka kap mesin. Sopir andal perlu bisa dua-duanya.
🔒 Begitu bisa login, hal pertama: ganti password admin! Router dengan password kosong yang tersambung ke internet bisa diambil alih orang dalam hitungan menit.
/user set admin password="Buat-Password-Kuat-123"

3. Internet Pertama — Lab Wajib 🧪

Skenario: kabel ISP masuk ke ether1, laptop/HP lewat ether2. Target: laptop bisa internet.

Ada 4 langkah dan semuanya wajib berurutan. Hafalkan pola ini — 90% konfigurasi dasar MikroTik hanya variasi dari 4 langkah ini:

# 1. WAN dapat IP otomatis dari ISP
/ip dhcp-client add interface=ether1 disabled=no

# 2. LAN diberi IP (gerbang bagi client)
/ip address add address=192.168.88.1/24 interface=ether2

# 3. Router tahu DNS (penerjemah nama ke IP)
/ip dns set servers=8.8.8.8,1.1.1.1 allow-remote-requests=yes

# 4. NAT: sembunyikan IP LAN di balik IP publik
/ip firewall nat add chain=srcnat out-interface=ether1 action=masquerade
💡 Analogi NAT: satu kantor punya 50 karyawan tapi 1 nomor telepon humas. Semua panggilan keluar "mengatasnamakan" humas — itulah masquerade.

Cek: /ip dhcp-client print (status harus bound), lalu dari laptop: ping 8.8.8.8 dan ping google.com. Kalau yang pertama jalan tapi kedua gagal → masalahnya DNS.

4. IP Address, DHCP & DNS

Tiga serangkai yang bikin jaringan "nyambung".

IP Address & Netmask

IP versi 4 seperti 192.168.88.1/24. Angka setelah garis miring (prefix) menentukan besar jaringan: /24 = 254 host, /30 = 2 host (untuk link antar-router), /32 = 1 IP. Bingung hitung? Pakai kalkulator subnet.

DHCP: tukang bagi IP otomatis

Daripada setting manual per laptop, aktifkan DHCP Server di interface LAN. Client dapat IP + gateway + DNS sekaligus.

# Server DHCP di ether2, sewa 1 hari
/ip pool add name=pool-lan ranges=192.168.88.10-192.168.88.200
/ip dhcp-server add name=dhcp-lan interface=ether2 address-pool=pool-lan disabled=no
/ip dhcp-server network add address=192.168.88.0/24 gateway=192.168.88.1 dns-server=192.168.88.1

Di WinBox: IP → DHCP Server → DHCP Setup (wizard otomatis, cocok untuk pemula).

DNS: buku telepon internet

Manusia ingat google.com, komputer butuh 142.250.x.x. Router bisa jadi "tukang tanya" (allow-remote-requests) agar client cukup mengarah ke IP router. Tambahan keren: Static DNS untuk blokir situs (/ip dns static add name=iklan.mengganggu address=127.0.0.1) atau arahkan domain ke server lokal.

5. Firewall & NAT

Satpam + resepsionis router. Dibaca dari atas ke bawah!

Tiga chain (jalur) utama

ChainArtinyaContoh
inputPaket yang tujuannya router itu sendiriLogin WinBox, DNS ke router
forwardPaket lewat router (client ↔ internet)Browsing, game, streaming
outputPaket dari router keluarPing/Netwatch dari router
💡 Analogi: input = tamu yang mau ketemu satpam. forward = tamu yang cuma lewat gerbang ke gedung lain. Aturan dibaca berurutan seperti daftar periksa — paket cocok aturan nomor 3 ya berhenti di situ.

Aturan dasar yang aman

# Terima yang sudah nyambung, buang yang rusak
/ip firewall filter add chain=input action=accept connection-state=established,related,untracked
/ip firewall filter add chain=input action=drop connection-state=invalid
/ip firewall filter add chain=input action=accept src-address=192.168.88.0/24
/ip firewall filter add chain=input action=drop comment="tolak sisanya"

NAT: masquerade vs port-forwarding

  • srcnat/masquerade — client LAN → internet (dibahas di Lab 3).
  • dstnat — internet → server di dalam LAN. Contoh: CCTV/server bisa diakses dari luar.
# Teruskan port 8080 dari publik ke DVR 192.168.88.10
/ip firewall nat add chain=dstnat dst-port=8080 protocol=tcp action=dst-nat to-addresses=192.168.88.10 to-ports=80

6. Routing & Failover Otomatis

Memberi tahu router "jalan" menuju tiap tujuan.

Static route = petunjuk jalan manual. Contoh: jaringan kantor cabang lewat VPN:

/ip route add dst-address=10.10.20.0/24 gateway=10.99.99.2

Failover 2 ISP (materi favorit mahasiswa!)

Triknya bernama recursive routing: masing-masing gateway "ditambatkan" ke IP publik (8.8.8.8 dan 1.1.1.1). Kalau ISP 1 mati, ping-check gagal → route utama nonaktif → traffic pindah ke ISP 2 otomatis.

/ip route add dst-address=8.8.8.8/32 gateway=192.168.1.1 scope=10 comment="cek-isp1"
/ip route add dst-address=1.1.1.1/32 gateway=192.168.2.1 scope=10 comment="cek-isp2"
/ip route add distance=1 gateway=8.8.8.8 check-gateway=ping comment="utama"
/ip route add distance=2 gateway=1.1.1.1 check-gateway=ping comment="cadangan"

Versi lengkap siap tempel ada di mikrotik-toolbox → 02-failover-2-wan.rsc.

Naik kelas: OSPF

Kalau router sudah banyak (kampus/hotel bertingkat), routing manual melelahkan. OSPF membuat router saling bertukar info jalan secara otomatis. Cukup aktifkan di tiap router + daftarkan network-nya — tabel route terisi sendiri.

7. Wireless (WiFi)

Mengubah router menjadi access point.

Konsep kunci: mode (ap-bridge = jadi pemancar, station = jadi penangkap), SSID (nama WiFi), security profile (WPA2 + password), channel/frequency (pakai yang sepi: 1, 6, atau 11 di 2,4 GHz).

/interface wireless security-profiles add name=aman mode=dynamic-keys authentication-types=wpa2-psk wpa2-pre-shared-key="PasswordWifiKuat"
/interface wireless set wlan1 mode=ap-bridge ssid="Lab-Jaringan" security-profile=aman frequency=2412 disabled=no
💡 Analogi channel: WiFi seperti orang ngobrol di ruangan. Kalau semua teriak di frekuensi sama, tidak ada yang terdengar jelas. Pindah channel = pindah meja yang sepi.

Untuk banyak AP (gedung/hotel): pakai CAPsMAN — 1 controller mengatur semua AP: SSID, password, dan channel terpusat. Topik bagus untuk tugas akhir!

8. VPN dengan WireGuard

Terowongan aman dari internet ke jaringan lokal.

WireGuard adalah VPN modern: cepat, simpel, dan sudah bawaan RouterOS 7. Dua pola umum:

  • Road-warrior — teknisi dari HP/laptop mengakses router & LAN kantor dari mana saja.
  • Site-to-site — menghubungkan 2 kantor seolah satu LAN.
# Di router kantor (ganti port bila perlu)
/interface wireguard add name=wg-admin listen-port=13231
/ip address add address=10.99.99.1/24 interface=wg-admin
/ip firewall filter add chain=input protocol=udp dst-port=13231 action=accept comment="izin WireGuard"

Tiap perangkat butuh key pair (public/private). Private key tidak boleh bocor — seperti password. Script lengkap + firewall-nya ada di toolbox 05-wireguard.

9. QoS & Limit Bandwidth

Biar Zoom tidak kalah dengan download.

Prinsip HTB (yang dipakai MikroTik): bandwidth dibagi seperti kue — ada jatah minimum yang dijamin (limit-at) dan maksimum boleh pinjam (max-limit) saat jalur sepi.

Cara gampang: Simple Queue

# Client 192.168.88.50: jatah 2 Mbps, boleh pinjam sampai 10 Mbps
/queue simple add name="client-50" target=192.168.88.50/32 limit-at=2M/2M max-limit=10M/10M

Cara rapi: Queue Tree + Mangle

Untuk banyak client: tandai paket dulu (mangle: game/zoom = prioritas 1, download = prioritas 8), lalu atur antreannya di queue tree. Prioritas kecil = didahulukan. Pola ini yang dipakai di hotel/kampus.

10. Hotspot + Voucher

WiFi warung/hotel yang login dulu baru internetan.

Hotspot mencegat user baru dan menampilkan halaman login. Cocok dipadukan dengan User Manager untuk jualan voucher waktu/kuota — sumber pemasukan RT/RW-net!

Langkah cepat via WinBox: IP → Hotspot → Hotspot Setup (wizard), pilih interface, DNS, sertifikat (bisa skip untuk lab), lalu buat user di IP → Hotspot → Users.

# Batasi 1 user: 2 Mbps, kuota 1 GB, 3 jam
/ip hotspot user profile add name=voucher rate-limit=2M/2M
/ip hotspot user add name=VOUCHER-001 password=abc123 profile=voucher limit-bytes-total=1073741824 limit-uptime=3h

11. Monitoring & Perawatan

Router yang tidak dipantau = bom waktu.

  • Netwatch — pantau host penting, jalankan script saat down/up. Digabung alert Telegram (lihat toolbox 04).
  • Backup + Export — file .backup hanya bisa dibuka tipe sama; /export (.rsc) bisa dibaca manusia & beda versi. Punya dua-duanya!
  • Scheduler — otomatisasi: backup harian, reboot mingguan, kirim laporan.
  • Logging — kirim log ke server (remote syslog) agar jejak tidak hilang saat router restart.
  • Update — System → Packages → Check For Updates. Baca changelog dulu untuk router produksi; update tengah malam.
  • The Dude — aplikasi gratis MikroTik untuk peta jaringan + monitoring banyak router sekaligus.

13. Tugas Praktikum Mahasiswa 🎓

Bisa dikerjakan di CHR/GNS3/EVE-NG bila perangkat terbatas.

  • Tugas 1 — Bangun Lab 3: sambungkan 1 client ke internet + DHCP server. Bukti: screenshot ping google.com dari client.
  • Tugas 2 — Hitung subnet untuk 4 divisi (masing-masing butuh 25 host) dari 192.168.10.0/24, lalu terapkan 1 subnet di router. (Bantuan: kalkulator subnet)
  • Tugas 3 — Terapkan firewall hardening + buktikan port telnet/FTP tertutup (scan dari client).
  • Tugas 4 — Simulasikan failover: 2 gateway, cabut kabel ISP 1, ukur berapa detik pindah + buktikan tanpa putus ping lama.
  • Tugas 5 — Bangun hotspot voucher untuk 5 user + batasi 2 Mbps, uji login dari HP.
  • Tugas 6 (kelompok) — Rancang jaringan hotel 3 lantai: VLAN tamu/kantor/CCTV, QoS Zoom prioritas, WireGuard untuk admin, presentasikan topologinya.
