# 📡 Belajar MikroTik

Materi jaringan MikroTik/RouterOS lengkap berbahasa Indonesia untuk pemula & mahasiswa: pengenalan, akses, lab internet pertama, IP/DHCP/DNS, firewall & NAT, routing & failover, wireless, WireGuard, QoS, hotspot voucher, monitoring, troubleshooting, tugas praktikum, kamus istilah, dan **kuis interaktif**.

🌐 **Web materi:** https://dulkemot.github.io/belajar-mikrotik/
